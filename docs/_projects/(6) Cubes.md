## Sobre o Jogo:

Cubes é um jogo 3D isométrico de puzzle. O desafio consiste em utilizar elementos do cenário para matar os cubos e assim usá-los para criar um caminho até o final da fase.

## About the Game:

Cubes is an isometric 3D puzzle game. The challenge consists of using elements from the scenery to kill the cubes and use them to create a path to the end of the level.
